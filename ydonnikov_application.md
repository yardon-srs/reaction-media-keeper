# Яромир Донников - "Хранилище медиа реакций"

### Группа: 10 - И - 3
### Электронная почта: yayudonnikov@edu.hse.ru


**[ НАЗВАНИЕ ПРОЕКТА ]**

"Хранилище медиа реакций"

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

Часто, в переписке или при написании постов, появляется потребность включить в сообщение/пост очень конкретную картинку/гифку/видео, но возникает сложность вспомнить как она была названа, где она хранилась и как вообще ее найти.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

* Активные пользователи мессенджеров/соцсетей
* СММ специалисты

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 

Мобильная версия:
* Android 7+
* 1 Гб постоянной памяти
* 4 Гб оперативной памяти

Десктопная версия:
* Поддерживаемые ОС и их минимальные версии те же, что и у Qt [(Клик!)](https://doc.qt.io/qt-6/supported-platforms.html)
* 1 Гб постоянной памяти
* 4 Гб оперативной памяти

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

* Добавление, удаление, переименование медиа в своей библиотеке
* Копирование медиа из своей библиотеки в буфер обмена устройства, экспорт медиа на устройство
* Сортировка медиа по дате добавления, количеству тэгов
* Добавление, удаление тэгов у медиа в своей библиотеке
* Создание, управление, удаление аккаунта (библиотека к нему и привязана)
* Создание, управление, удаление коллекций медиа
* Создание уникальной постоянной ссылки на медиа или коллекцию медиа
* Возможность поиска по тексту на картинке (.gif и видео будет слишком тяжело поддерживать)
* Возможность использовать приложение без соединения с интернетом или аккаунта, но после выхода в сеть/входа в аккаунт локальная библиотека будет синхронизироваться с той, что на сервере
* Несколько языков интерфейса, темы (светлая/темная/системная)

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

* [meme-magager (Декстопное Tauri приложение)](https://github.com/0adiy/meme-manager) - нет коллекций, облака, возможности поделиться, распознавания текста, только на пк
* [MemeOrganizer: Meme Manager (Android приложение)](https://play.google.com/store/apps/details?id=com.taskharmony.memeorganizer&hl=en) - нет облака, распознавания текста, возможности поделиться, только мобильная версия
* [Meme Library (мобильное приложение)](https://play.google.com/store/apps/details?id=com.devbymitch.maFlutter) - нет облака, только мобильная версия

**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

* Kotlin / Android Studio / SQLite - Для мобильного Android приложения
* C++ Qt - Для десктопного приложения
* Python FastAPI или Rust Axum - для сервера (пока не решено)
* PostgreSQL - БД

**[ ЭТАПЫ РАЗРАБОТКИ ]**

* Разработка пользовательских сценариев
* Дизайн пользовательского интерфейса
* Проектирование API сервера
* Разработка десктопной версии (локальной части)
* Параллельная разработка серверной части, ее взаимодействия с БД и онлайн части десктопной версии
* Разработка мобильной версии
* Тестирование
* Подготовка к защите

**[ ВОЗМОЖНЫЕ РИСКИ ]**

* Не хватило времени: можно ускорить разработку с использованием недавних технологических прорывов.
* Ошибка в дизайне/плане API: придеться переделывать дизайн/API
* Выбран неправильный (по разным причинам) стэк технологий: придется изучить новые технологии и переписать уже существующий код на новый стэк.
